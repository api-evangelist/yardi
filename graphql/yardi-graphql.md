# Yardi GraphQL API

Yardi is a property management and real estate investment platform. The API covers property records, lease management, resident/tenant data, financial transactions, maintenance orders, commercial property, and investment portfolio analytics.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Yardi REST API
**Documentation:** https://www.yardi.com/platform/api/

- Reference: https://www.yardi.com/services/interfaces/standard-interface-options/
- Schema: https://github.com/api-evangelist/yardi
